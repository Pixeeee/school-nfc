# Android Firebase configuration

Create an Android app in each Firebase project using application ID:

```text
com.pixeeee.schoolnfc
```

Download that environment's `google-services.json` and place it at:

```text
apps/teacher-mobile/android/app/google-services.json
```

The file is intentionally ignored by Git. Never commit a production service-account key.
Register the debug, staging, and production signing-certificate SHA-256 fingerprints in
Firebase before enabling Play Integrity/App Check enforcement.
